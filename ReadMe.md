# Zobject - Object-Oriented Programming Emulator

Zobject is a small library designed to emulate object-oriented programming in C. It forms part of my ML stack and helps in maintaining modular and clean code across the various projects.

**Highlights:**
- Provides basic object-oriented features in C.
- Essential for cleaner code architecture within the ML stack.
- Built using CMake.

## Getting Started

Clone the repository and build:
```bash
git clone https://github.com/iudah/zobject.git
cd zobject
cmake .
make
```
